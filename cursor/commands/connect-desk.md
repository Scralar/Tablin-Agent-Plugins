# Connect Tablin

1. On the desk, open **Settings**, then **Agent link**. Choose **Connect** if this PC is not paired, then turn **Turn Agent link on** on.
2. In Cursor, open **Customize** and choose **Authenticate** on the **tablin** server of Tablin for Cursor. The address is already `https://3.9.77.189/mcp`.
3. Sign in when the browser opens. There is no secret to paste.
4. Call `tablin_status`, then `guide_read`, before other tools. Confirm before a delete, a screen, or a bulk change. Writes show live in the app.
