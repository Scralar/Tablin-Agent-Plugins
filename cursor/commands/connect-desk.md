# Connect Tablin

1. On the desk, open **Settings**, then **Agent link**. Choose **Connect** if this PC is not paired, then turn **Turn Agent link on** on.
2. In Cursor, open **Customize** and choose **Authenticate** on the **tablin** server of Tablin for Cursor. The address is already set.
3. Sign in when the browser opens. There is no secret to paste.
4. Call desk_status with pluginVersion "3.0.3" first, then guide_read when you need workflows. Confirm before deletes, screens or bulk changes.
