# Tablin Agent link for Cursor

Address: https://3.9.77.189/mcp

1. Copy this folder to `~/.cursor/plugins/local/tablin-agent-link` (on Windows, `%USERPROFILE%\.cursor\plugins\local\tablin-agent-link`) and restart Cursor.
2. Open **Settings > Tools & MCP**, find **tablin**, and choose **Authenticate**. (Older installs named it **desk**; remove that one.)
3. Or copy the `tablin` entry from `mcp.json` into `~/.cursor/mcp.json`.

Sign in with the same account that paired the desk under Settings > Agent link > This PC. A different account will not reach this desk.

Keep the desk open with **Settings > Agent link** turned on while you work.
