# Tablin Agent link for Gemini CLI

Address: https://3.9.77.189/mcp

1. Run `gemini extensions install` followed by the path to this folder.
2. Start Gemini CLI and run `/mcp auth tablin`, then sign in in the browser.
3. No extension? Run `gemini mcp add --transport http tablin https://3.9.77.189/mcp` instead.

Sign in with the same account that paired the desk under Settings > Agent link > This PC. A different account will not reach this desk.

Keep the desk open with **Settings > Agent link** turned on while you work.
