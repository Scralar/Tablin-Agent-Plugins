# Tablin Agent link for VS Code

Address: https://3-9-77-189.sslip.io/mcp

1. In VS Code, run **Chat: Install Plugin from Source** from the Command Palette and enter the path to this folder. Turn on `chat.plugins.enabled` if it asks.
2. Open the MCP server list, start **tablin**, and sign in when the browser opens.
3. Use Copilot Chat in **Agent** mode. The skill shows under **Configure Skills**.

Use the same account you use with your agent.

Keep the desk open with **Settings > Agent link** turned on while you work.
