# Tablin Agent link for Windsurf

Address: https://3-9-77-189.sslip.io/mcp

1. Windsurf has no plugin package. In Windsurf, open the MCP settings and choose **View raw config** (`~/.codeium/windsurf/mcp_config.json`).
2. Add the `tablin` entry from `mcp_config.json` to it, save, refresh, and sign in when the browser opens.
3. Copy the `skills/tablin-agent-link` folder to `~/.codeium/windsurf/skills/` (or a project's `.windsurf/skills/`).

Use the same account you use with your agent.

Keep the desk open with **Settings > Agent link** turned on while you work.
